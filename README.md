# Projeto-Integrador-2---Testes-de-carga
Testes de carga para o marketplace de hardware do trabalho de PI2
Utilizando uma população de 2000 instâncias de Usuários, 1000 anúncios, 1000 modelos de hardware, 1000 categorias, 500 pedidos, 1000 disputas, 1000 evidências, 1000 envios, 1000 contas custodias, calculamos a latência da execução das ações de "Fazer pedido" e "Criar anúncio".
Os endpoints foram feitos em javascript e os testes foram feitos para serem usados com a ferramenta Grafana k6.
